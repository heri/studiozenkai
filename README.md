
# Studio Zenkai Website

This repository contains the source code for the Studio Zenkai website, which is deployed to GitHub Pages at [studiozenkai.com](https://studiozenkai.com).

## Overview

Studio Zenkai is dedicated to the craft of programming, photography, and living sustainably. The site is built using [Hugo](https://gohugo.io), an open-source static site generator written in Go. The pages are rendered using Handlebars templates.

## Deployment

To deploy the site, you need to have write permissions. The deployment process involves building the site and copying the generated files to the appropriate directories.

### Deployment Command

```sh
deploy.sh
```
This command will build the site and deploy it to the target directory. Make sure you have the necessary permissions to execute this script.
